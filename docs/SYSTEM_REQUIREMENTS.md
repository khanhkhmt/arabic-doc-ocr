Below the GPU minimum dots.mocr cannot read the page at 2400 px and falls back to the original size (printed text on page 1: 90.3 % → 77.6 % correct characters). The line reader needs batch size 1, so a bigger GPU does not make it faster.

## Maximum (what the software can use)

- GPUs: at most 2 per process (dots on one, line reader on the other); more GPUs are not used. For more throughput run several processes, each with its own `--dots-device` / `--htr-device`.
- GPU memory beyond 21 GB on one GPU (or 14 GB per GPU with two) brings no speed-up.
- The web interface handles one request at a time (queue).
- RAM: the measured peak was 20.2 GB; more RAM is not used.

## Setting checked by these numbers

`config.ONE_GPU_BOTH_MODELS_GB = 22`: with one GPU of at least this size `--offload auto` keeps both models loaded. Measured need: 21 GB → OK.
